Press Start UA Launcher — портативна версія для Windows
=======================================================

Встановлювати нічого не треба.

1. Розпакуйте архів у будь-яку папку (наприклад, на Робочий стіл або флешку).
2. Запустіть «Press Start UA Launcher.exe».

Якщо Windows покаже синє вікно «Windows захистив ваш ПК»: натисніть «Докладніше» →
«Виконати все одно». Програма не має платного цифрового підпису, тому Windows її не знає.

Налаштування і завантажені патчі програма зберігає поруч із собою, у папці «data».
Щоб видалити програму, просто видаліть її папку.

Для перекладу потрібна ваша власна копія гри (образ ISO, WBFS…). Образ RVZ можна
пропатчити просто в браузері: https://press-start-ua.github.io/launcher/
